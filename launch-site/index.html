troubleshooting

When macOS gets picky, check these first.

Permissions matter

  • Microphone is required for recording.
  • Input Monitoring is required for hotkeys.
  • Accessibility is required for auto-paste and selected-text context.
  • If permissions act weird, remove and re-add Murmur in Accessibility and Input Monitoring.
  • After permission changes, quit and reopen Murmur.

If hotkeys, paste, or context fail

  • If macOS intercepts Fn, use the floating Transcribe/Rewrite buttons.
  • Fn + Control rewrite needs internet and an OpenAI key.
  • Selection context depends on whether the frontmost app exposes highlighted text to macOS Accessibility.
  • If an app hides the selection, Murmur continues without context and logs the reason in the Debug Panel.
  • Use the Debug Panel to check recording, transcription, paste, permissions, context, and API failures.

Install Murmur

Requires macOS 14+. Apple Silicon is recommended. Run the installer, grant Microphone, Accessibility, and Input Monitoring permissions, then add an OpenAI key if you want Fn + Control polish mode.

$ curl -fsSL https://raw.githubusercontent.com/LucianaMa1/murmur/main/install.sh | bash
