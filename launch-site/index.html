case study

Building a voice keyboard that stays out of the way.

Model selection

Raw dictation stays local for speed and privacy. AI rewrite uses text only, so the expensive model is reserved for tone, structure, and replies—not audio.

Interaction design

Fixed hotkeys beat a complex command palette: Fn for capture, Fn + Control for AI. The tradeoff is less customization, but the muscle memory is predictable.

Iterations

The product moved from “dictation app” to “voice keyboard”: release-to-paste, selected-text context, floating fallback controls, and a debug panel for macOS permission edge cases.

The main product bet: keep the workflow native and boring, then let AI improve the sentence after the user speaks naturally.
